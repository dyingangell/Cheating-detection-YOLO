# 3. Предлагаемый метод

## 3.1 Нормализация положения головы

Расстояние от камеры до определённого человека может меняться, что искажает масштаб и точную оценку. Для устранения зависимости от расстояния положение носа нормализуется относительно средней точки плеч и масштабируется на ширину плеч:

```
rel_x = (nose_x - mid_shoulder_x) / shoulder_width
rel_y = (nose_y - mid_shoulder_y) / shoulder_width
```

Ключевые точки принимаются во внимание только при условии, что уверенность детектора превышает порог c_min = 0.30. При более низкой уверенности кадр пропускается, чтобы исключить шумные оценки позы.

---

## 3.2 Автокалибровка индивидуального профиля

У каждого человека свой индивидуальный базовый профиль позы, поэтому выполняется индивидуальная калибровка под каждого студента отдельно по методу экспоненциального скользящего среднего:

```
base_x(t) = (1−α)·base_x(t−1) + α·rel_x(t),  α = 0.1
base_y(t) = (1−α)·base_y(t−1) + α·rel_y(t),  α = 0.1
```

Калибровка выполняется в течение первых T_calib = 30 с после появления объекта в кадре. Увеличенное по сравнению с прежними 10 с окно позволяет охватить естественные колебания позы — письмо, паузы, взгляд на доску — и сформировать устойчивый базовый профиль, снижая число ложных срабатываний.

---

## 3.3 Разделение латерального и глубинного отклонений

При съёмке потолочной камерой наклон головы вперёд для письма и боковой взгляд в сторону соседа проявляются в разных пространственных направлениях. Для их различения вводятся независимые компоненты отклонения:

```
lateral_dev = |rel_x − base_x|   (горизонтальное, вдоль ряда парт)
depth_dev   = |rel_y − base_y|   (продольное, вперёд/назад)
```

Полное Евклидово расстояние используется только для обнаружения отсутствия студента в кадре:

```
dist = √(lateral_dev² + depth_dev²)
```

Если dist > D_away = 1.2, объект классифицируется как покинувший своё место, накопление счёта приостанавливается.

---

## 3.4 Подавление позы письма

Поза письма характеризуется значительным продольным смещением при малом латеральном. Вводится коэффициент подавления R_suppress = 1.5: если глубинное отклонение превышает латеральное более чем в R_suppress раз, эффективное латеральное смещение уменьшается:

```
если depth_dev > lateral_dev · R_suppress:
    effective_lateral = lateral_dev · 0.3
иначе:
    effective_lateral = lateral_dev
```

Это позволяет системе не реагировать на нормальное поведение студента при работе с бланком ответов.

---

## 3.5 Поправка на перспективное сжатие

При наклонной установке камеры студенты, сидящие в дальних рядах, проецируются с меньшей видимой шириной плеч, что искусственно завышает нормализованное отклонение носа. Для компенсации вводится адаптивный радиус нормальной зоны, масштабируемый по вертикальной позиции центра ограничивающего прямоугольника:

```
y_frac = bbox_cy / H_frame
R_eff  = R_base · (1 + k_f · y_frac),   k_f = 0.4,  R_base = 0.38
```

Студенты в дальних рядах (высокий y_frac) получают бо́льший радиус допуска, что выравнивает чувствительность системы по всей аудитории.

---

## 3.6 Вычисление латерального избытка и временное накопление подозрительности

Латеральный избыток определяется как превышение эффективного латерального отклонения над адаптивным радиусом нормальной зоны:

```
lateral_excess = max(0, effective_lateral − R_eff)
```

Вместо обвинений за один кадр используется накопительная система. Если обнаруживается нарушение (lateral_excess > 0), счёт увеличивается пропорционально величине избытка; при возврате в нормальную зону счёт затухает:

```
score(t) = min(score(t−1) + k · lateral_excess · dt, S_max),  если lateral_excess > 0
score(t) = max(score(t−1) − 0.2·dt, 0),                       если lateral_excess = 0

k = 1.0,   S_max = 15 с
```

Медленное затухание (коэффициент 0.2) позволяет системе накапливать подозрительность при прерывистом поведении: если студент смотрит в сторону несколько раз по 2–3 секунды с паузами, счёт не сбрасывается до нуля, а суммируется. Пропорциональное накопление (k · lateral_excess) означает, что более резкие отклонения головы приводят к более быстрому росту счёта.

---

## 3.7 Подавление при ходьбе

Если смещение центра ограничивающего прямоугольника между соседними кадрами превышает порог T_walk = 30 пикселей, объект классифицируется как находящийся в движении и счёт затухает с удвоенной скоростью:

```
move = √((cx_t − cx_{t−1})² + (cy_t − cy_{t−1})²)

если move > T_walk:
    score(t) = max(score(t−1) − 2·dt, 0)
```

---

## 3.8 Генерация предупреждения

Если счёт превышает порог T_warn, формируется предупреждение о возможном списывании. После первого срабатывания объект переходит в состояние ожидания подтверждения оператором (PENDING), что исключает повторные уведомления по тому же эпизоду:

```
если score(t) ≥ T_warn:
    Warning = True

T_warn = 3.0 с
```

Порог 3.0 с в сочетании с медленным затуханием (0.2/с) даёт возможность обнаруживать как непрерывные эпизоды (3 с подряд), так и прерывистые (например, три взгляда по 1–2 с с короткими паузами). Прежний порог 10.0 с требовал длительного непрерывного отклонения, что не соответствовало реальному поведению нарушителей.

Оператор подтверждает факт нарушения или отмечает событие как ложное срабатывание. В последнем случае накопленный профиль студента сбрасывается и возобновляется через T_cooldown = 120 с.
